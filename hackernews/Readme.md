# HackerNews GraphQL API

This project implements a **GraphQL API** using Go with a hexagonal architecture. It is designed to illustrate how to structure a project with input and output adapters, domains, services, and ports.

The API includes a simple example of handling GraphQL queries with dummy responses for educational purposes.

---

## Project Structure

The project follows a hexagonal architecture:

```
internal/
├── adapters/       # Adapters (input and output)
│   ├── in/       # Input adapters (GraphQL)
│   │   ├── graph/  # GraphQL implementation
│   │       ├── model/      # Models generated by gqlgen
│   │       ├── resolvers/  # GraphQL resolvers
│   │       ├── schemas/    # GraphQL schema (definition)
│   │       └── generated.go # Code generated by gqlgen
│   ├── out/      # Output adapters (MySQL)
│       ├── db/mysql/   # Database repository
│       │   ├── config.go
│       └── link_repository.go
├── core/           # Core logic (domains, ports, and services)
    ├── domains/   # Domain models
    ├── ports/     # Port interfaces
    └── services/  # Service implementations
```

## Setup

### Requirements

- Go 1.20+
- MySQL (optional if you want to integrate a real database)

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/your_user/hackernews-graphql-api.git
   cd hackernews-graphql-api
   ```

2. Install dependencies:

   ```bash
   go mod tidy
   ```

3. (Optional) Configure database access in `internal/adapters/out/db/mysql/config.go`.

4. Run the server:

   ```bash
   go run cmd/server.go
   ```

## Using the API

### GraphQL Query Examples

The server includes a basic GraphQL implementation. To test it, you can use tools like [GraphiQL](https://github.com/graphql/graphiql) or [Postman](https://www.postman.com/).

### Example Schema (`schema.graphql`)

```graphql
type Query {
  links: [Link!]!
}

type Link {
  id: ID!
  title: String!
  url: String!
}
```

### Example Resolver

The resolver for the `links` query returns a list of dummy responses:

```go
package resolvers

import (
	"context"
	"hackernews/internal/adapters/in/graph/model"
)

type Resolver struct{}

func (r *Resolver) Links(ctx context.Context) ([]*model.Link, error) {
	return []*model.Link{
		{
			ID:    "1",
			Title: "Google",
			URL:   "https://www.google.com",
		},
		{
			ID:    "2",
			Title: "GitHub",
			URL:   "https://www.github.com",
		},
	}, nil
}
```

### Example Query

Test the API by sending the following query:

```graphql
query {
  links {
    id
    title
    url
  }
}
```

**Dummy Response:**

```json
{
  "data": {
    "links": [
      {
        "id": "1",
        "title": "Google",
        "url": "https://www.google.com"
      },
      {
        "id": "2",
        "title": "GitHub",
        "url": "https://www.github.com"
      }
    ]
  }
}
```

## Customization

You can extend the GraphQL schema in `internal/adapters/in/graph/schemas/` and add more resolvers in `internal/adapters/in/graph/resolvers/` according to your project needs.

### Connecting to a Database

Currently, the project returns dummy data, but you can modify the resolvers to fetch real data from the database using the repository located in `internal/adapters/out/db/mysql/`.

Example:

```go
func (r *Resolver) Links(ctx context.Context) ([]*model.Link, error) {
	links, err := r.linkRSrv.GetAllLinks(ctx) // Real implementation
	if err != nil {
		return nil, err
	}
	return links, nil
}
```
